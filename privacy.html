Политика конфиденциальности

«Personal assistant» — личное приложение одного пользователя (владельца). Доступ к данным Google (Gmail, Календарь, Таблицы, Диск) приложение получает только с его согласия и использует исключительно для выполнения его собственных поручений.

  • Данные не передаются, не продаются и не раскрываются третьим лицам.
  • Данные не используются для рекламы и не используются для обучения моделей.
  • Токены доступа хранятся в зашифрованном виде на личном сервере владельца.
  • Доступ можно отозвать в любой момент: myaccount.google.com/permissions.

Использование данных, полученных из API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Privacy policy (English)

"Personal assistant" is a single-user personal app. It accesses the owner's Google data only with the owner's consent and only to carry out the owner's own requests. Data is never sold, shared with third parties, used for advertising or used to train models. Tokens are stored encrypted on the owner's private server. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
